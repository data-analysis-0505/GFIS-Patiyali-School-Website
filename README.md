# Golden Future International School — Patiyali

Premium original Next.js school website demo for:
**Golden Future International School, Nardoli Bypass, Patiyali, Uttar Pradesh**

Academic range: **Nursery to Class XII**

## Run locally

Requirements: Node.js 20+

```bash
npm install
npm run dev
```

Open: http://localhost:3000

## Production build

```bash
npm run build
npm start
```

## Important client content

This demo intentionally does NOT invent official phone numbers, email, fees, teacher names, certificates, CBSE affiliation numbers, results, or social-media profiles. Replace the clearly marked placeholders with school-approved information.

CBSE requires affiliated schools to maintain a functional website with comprehensive school information and Mandatory Public Disclosure. See the official CBSE circulars and bye-laws before publishing compliance information.

## Production backend

The contact route currently logs enquiries server-side. For production, connect a database/email provider such as Supabase/Postgres and add authenticated admin CRUD for notices, news, gallery, faculty, admissions, results and documents.

## Social links

The left social rail currently uses generic Instagram/Facebook/YouTube destinations. Replace them with the school's verified official profiles.

## Domain

Recommended primary domain: `www.gfispatiyali.com` if available. Register it in the school's/client's name and account.
